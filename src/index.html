Dokumentasi & Panduan Penggunaan ReySkripsi Add-in

Artikel • Terakhir Diperbarui: 12/08/2026 • Tim ReySkripsi

ReySkripsi adalah Microsoft Word Add-in modern yang dirancang khusus untuk mempercepat dan mempermudah penyusunan skripsi, tesis, dan artikel ilmiah sesuai standar akademik Indonesia.

Semua Fitur Utama ReySkripsi

ReySkripsi menyediakan berbagai alat otomatisasi serbaguna yang dapat langsung diakses melalui panel samping (Taskpane) Microsoft Word Anda:

1. Auto Caption Bab

Membuat penomoran caption Tabel & Gambar otomatis sesuai Bab (contoh: Tabel 1.1, Tabel 2.1). Menggunakan Native Word Field (SEQ) sehingga mendukung Update Field dan Daftar Tabel otomatis.

2. Auto Language & KBBI Scanner

Mendeteksi kata-kata bahasa asing dalam dokumen yang belum tercantum di KBBI dan memiringkannya (Italic) secara otomatis maupun terpilih.

3. Batch Manual Italic

Memiringkan kata-kata tertentu sekaligus di seluruh dokumen atau seleksi teks dengan fleksibilitas sensitivitas huruf (Match Case).

4. Ask AI Assistant

Asisten AI pintar untuk berkonsultasi, menganalisis, dan merevisi isi skripsi berdasar konteks dokumen lengkap dengan rujukan sitasi.

5. AI Auto-Summarize Caption

Meringkas isi tabel menjadi deskripsi caption ringkas (maksimal 4 kata) menggunakan AI secara efisien dalam 1x panggilan batch request (anti-429 limit).

6. Terenkripsi & Aman (Settings)

Penyimpanan API Key sensitif (Gemini / NVIDIA) tersimpan aman dan terenkripsi menggunakan IndexedDB Lokal, terisolasi dari inspection browser.

Unduh & Panduan Pemasangan

Untuk mulai menggunakan ReySkripsi di Microsoft Word Anda, silakan unduh aplikasi ReySkripsi Manager di bawah ini:

Unduh reyskripsi-manager.exe

Langkah-langkah memasang ReySkripsi di Microsoft Word Desktop (Windows):

  1. Unduh aplikasi reyskripsi-manager.exe melalui tombol unduh di atas.
  2. Klik Ganda (Double Click) file installer tersebut.
  3. Klik tombol Install Add-in pada jendela installer dan tunggu notifikasi sukses.
  4. Buka aplikasi Microsoft Word, lalu pilih dokumen baru.
  5. Pergi ke tab Home (Beranda) > klik menu Add-ins > pilih My Add-ins.
  6. Klik ikon ReySkripsi untuk memunculkan sidebar add-in di Word Anda.

Langkah-langkah untuk Microsoft Word Web (Browser):

  1. Buka Word di Web dan buat dokumen baru.
  2. Pilih tab Home atau Insert di pita menu atas.
  3. Klik menu Add-ins > pilih Upload My Add-in (Unggah Add-in Saya).
  4. Pilih file manifest.xml dari repository project, lalu klik Upload.

Menghapus Add-in ReySkripsi dari komputer:

  1. Buka kembali aplikasi reyskripsi-manager.exe.
  2. Klik tombol Uninstall.
  3. Restart Microsoft Word jika sedang terbuka.
