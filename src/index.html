Membuat dan Mengonfigurasi ReySkripsi Word Add-in

Rey Workbench (Reynald Silva)
• Terakhir Diperbarui: 12/08/2026

Dalam penyusunan karya ilmiah dan skripsi, ReySkripsi adalah wadah otomatisasi cerdas yang menerapkan standar format akademik Indonesia (KBBI & Pedoman Ejaan) langsung di dalam Microsoft Word.

Fitur Utama Add-in

  1. Auto Caption Bab: Penyisipan caption otomatis untuk Tabel & Gambar berdasar nomor BAB (Contoh: Tabel 1.1). Terintegrasi dengan Word Native SEQ Field.
  2. KBBI & Foreign Word Scanner: Mendeteksi kata-kata bahasa asing dalam dokumen yang belum tercantum di KBBI dan memiringkannya (Italic) secara otomatis.
  3. Batch Manual Italic: Memiringkan kata-kata tertentu sekaligus di seluruh dokumen atau seleksi teks dengan opsi Match Case.
  4. Ask AI Assistant: Konsultasi dan analisis naskah berbasis AI (Gemini 3) langsung berdasarkan konteks isi dokumen Word Anda.
  5. AI Auto-Summarize Caption: Meringkas data tabel/gambar menjadi judul caption (maks 4 kata) menggunakan AI dalam 1x panggilan batch request hemat token.
  6. Penyimpanan Terenkripsi: API Key sensitif disimpan aman secara lokal menggunakan IndexedDB perangkat Anda.

Tampilan Antarmuka Aplikasi Add-in:

Buat dan Pasang Add-in

  1. Unduh file installer reyskripsi-manager.exe:

    Unduh reyskripsi-manager.exe

  2. Klik ganda (double click) file installer, lalu pilih Install Add-in.

  3. Buka Microsoft Word > pilih tab menu Home (Beranda) > pilih Add-ins > My Add-ins > klik ikon ReySkripsi.

  1. Buka Word di Web (word.office.com) dan buat atau buka dokumen baru.

  2. Pergi ke tab Home atau Insert, lalu klik menu Add-ins.

  3. Pilih Upload My Add-in dan pilih file manifest.xml dari komputer Anda.
