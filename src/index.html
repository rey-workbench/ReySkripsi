Panduan Lengkap Menginstal dan Menggunakan ReySkripsi Word Add-in

Rey Workbench (Reynald Silva) Author
Dibuat khusus untuk kemudahan penulisan skripsi & karya ilmiah

Halo semuanya!

Saya telah mengembangkan ReySkripsi, sebuah Microsoft Word Add-in praktis untuk otomatisasi penulisan skripsi dan makalah ilmiah sesuai standar akademik Indonesia (KBBI & Pedoman Ejaan).

Daftar Fitur Unggulan:

1. Auto Caption Bab
Penyisipan caption otomatis untuk Tabel & Gambar berdasar nomor BAB (Contoh: Tabel 1.1, Tabel 2.1). Menggunakan Native Word SEQ Field yang otomatis terhubung dengan Daftar Tabel / Daftar Gambar Word.

2. KBBI & Foreign Word Scanner
Mendeteksi kata-kata bahasa asing dalam dokumen yang belum tercantum di KBBI dan memiringkannya (Italic) secara otomatis maupun terpilih.

3. Batch Manual Italic
Memiringkan kata-kata tertentu sekaligus di seluruh dokumen atau seleksi teks dengan fleksibilitas sensitivitas huruf (Match Case).

4. Ask AI Assistant
Asisten AI pintar (Gemini 3) untuk berkonsultasi, menganalisis, dan merevisi naskah skripsi berdasar konteks dokumen lengkap dengan rujukan sitasi.

5. AI Auto-Summarize Caption
Meringkas data tabel/gambar menjadi judul caption (maks 4 kata) menggunakan AI secara efisien dalam 1x panggilan batch request.

6. Terenkripsi & Aman (Settings)
API Key sensitif (Gemini / NVIDIA) tersimpan aman dan terenkripsi menggunakan IndexedDB Lokal perangkat Anda.

Tampilan Antarmuka Aplikasi Add-in:

Cara Pemasangan Sangat Mudah (3 Langkah Cepat)

Untuk Word Desktop (Windows)

1
Unduh Aplikasi Installer:
Klik di sini untuk mengunduh reyskripsi-manager.exe
2
Jalankan Installer:

Klik 2x file reyskripsi-manager.exe, lalu klik tombol Install Add-in.

3
Buka Microsoft Word:

Buka MS Word > Pergi ke tab menu Home (Beranda) > klik Add-ins > pilih My Add-ins > klik ikon ReySkripsi. Selesai!

Untuk Word Versi Web (Browser)

Buka Word di Web > Pilih tab Home/Insert > Add-ins > Upload My Add-in > Pilih file manifest.xml.
